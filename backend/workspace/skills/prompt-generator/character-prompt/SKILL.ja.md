# キャラクター最終プロンプト（左側：正面顔クローズアップ ＋ 右側：三面図）

生成するのはキャラクター設定参照画像（character reference sheet）1枚。構図は固定：

- **左側：正面顔クローズアップ**——頭部と肩部の正面アップ。顔立ち、髪型、肌質がはっきり見え、顔の識別性のアンカーとなる
- **右側：正面、90度側面、背面の3枚の等高全身ビューを並列表示**——同一キャラクターの3つの全身ビューを等高で並べ、頭頂と足裏を揃える

**中核原則：一貫性 ＞ 美しさ。** この画像は後続のすべてのキャラクター画像・動画参照の外見のアンカーであり、中立的で、明瞭で、再利用可能でなければならない——単独の1枚としての芸術性を追求しない。

**参照画像がある場合、参照画像が外見の基準である。** ユーザーが参照画像をアップロードしたとき、その画像の人物が唯一の外見の出所である。プロンプトの役割は**指し示すこと**（「参照画像と同じ人物」）と**構図**（三面図の並べ方）であり、この人物をデザインし直すことではない。実測結果：テキストが参照画像と衝突すると、出力は**テキストに従う**——参照画像が白い紗に金刺繍の仙侠風ドレスでも、テキストに「ベージュの部屋着」と書けばその顔でベージュの部屋着が出る。参照画像モードでは、外見や服装の記述は1文ごとに参照画像との**競合**であり、補足ではない。

## 原設定の忠実な再現（最優先の制約）

キャラクターの `appearance`（容姿）と `styling`（装い）こそがそのキャラクターの原設定であり、ユーザー提供の参照画像や脚本に由来する。**最終プロンプトは元の外見と服装を項目ごとに忠実に転写しなければならず、要約・差し替え・美化・勝手なデザイン変更をしてはならない**——三面図はパイプライン全体の外見のアンカーであり、ここで服を1着変えれば後続のすべての画像・動画がその誤りを引き継ぐ。

**優先順位：参照画像 ＞ `appearance`／`styling` のテキスト。** 両者が一致するときは上記のとおり項目ごとに転写する。衝突するときは参照画像を優先し、衝突した項目は**書かない**（書けばテキストで参照画像を上書きすることになる）。参照画像がない場合、テキストが唯一の出所であり、すべて書き切らなければならない。

- **顔立ち／髪型**：輪郭、目の形、眉の形、髪の長さとスタイルを個別に書き出す。「整った顔立ち」「長い髪」のような一般語に圧縮しない
- **メイク／肌**：肌の色と質感、チーク、唇の色とツヤ、アイメイク（ライン／シャドウ／まつげ）、眉の形を個別に書き出す。**最も漏れやすい項目**——書かなければデフォルトに委ねられ、すっぴんや汎用的な濃いメイクになり、元設定の唇の色・肌の色・妆面と合わなくなる
- **服装**：デザイン ＋ 色 ＋ 素材 ＋ レイヤー（インナー／上掛け／腰帯など）＋ 状態を書き切る。例：「白い半透明の紗の上掛け、その下に白いストラップレスの胸衣、胸前に金色の瓔珞、金色の腰帯」——「白い漢服の上衣」だけで済ませない
- **アクセサリー**：原設定に登場する耳飾り・首飾り・髪飾り・額飾りなどはすべて個別に残し、省略も統合もしない
- **創作しない**：原設定にないディテールを勝手に足さない。判断に迷ったら元の文言をそのまま残し、別の服装で上書きしない

## 出力構造（この順序で1段落の連続した記述を組み立てる。言語はセッションの言語指令に従う）

**参照画像がある場合**はこちら——冒頭で参照画像を外見の基準として固定し、スロットには参照画像で見えている識別点だけを書き、項目を並べ立てない：

```
参照画像と同じ人物を基準とする。輪郭・顔立ち・髪型・肌の色・メイク・服装・アクセサリーはすべて参照画像のまま保持し、変えるのは角度と構図だけ。
キャラクター設定参照画像。左側は正面顔クローズアップ、右側は正面・90度側面・背面の3枚の等高全身ビューを並列表示。
クローズアップと全身ビューはすべて同一キャラクター。全身が画面に収まり、中立的なA字の立ち姿。3枚の全身ビューは等高で並び、頭頂と足裏が揃っている。
[参照画像で実際に見えていて、かつ強調する価値のある識別点のみ：年齢感 ＋ 体格 ＋ 象徴的な顔立ち／髪型／服装の要点]。
正面顔クローズアップと3つのビューの顔・髪型・服装は完全に一致。メイクとアクセサリーも同様に一致し、参照画像と同一人物である。
純白の背景、柔らかく均一な光線、映画の質感
```

**参照画像がない場合**はこちら——テキストが唯一の出所なので、スロットはすべて書き切る：

```
キャラクター設定参照画像。左側は正面顔クローズアップ、右側は正面・90度側面・背面の3枚の等高全身ビューを並列表示。
クローズアップと全身ビューはすべて同一キャラクター。全身が画面に収まり、中立的なA字の立ち姿。3枚の全身ビューは等高で並び、頭頂と足裏が揃っている。
[年齢感 ＋ 性別感 ＋ 体格]、[顔立ちの特徴]、[メイクと肌]、[髪型]。
[服装：デザイン ＋ 色 ＋ 素材 ＋ レイヤー ＋ 状態]、[アクセサリー：一点ずつ列挙し、統合しない]。
正面顔クローズアップと3つのビューの顔・髪型・服装は完全に一致。メイクとアクセサリーも同様に一致。
純白の背景、柔らかく均一な光線、映画の質感
```

## 参照画像モードのルール（ユーザーが参照画像をアップロードした場合）

参照画像はすでにその人物の外見情報をすべて備えている。テキストの役割は**それを覆い隠さないこと**：

- **参照画像に見えているものだけを書く**：スロットの各項目は参照画像上で指し示せなければならない。参照画像にないデザイン・色・髪型は書かない
- **選択肢から選ばない**：原設定に「または／例えば／いずれか」といった選択表現があるとき（例：「柔らかく体に沿う部屋着、色は暖色系（例えばベージュ、薄いピンク、または濃いグレー）」）、**そのうちの一つを選んで書き込まない**——一つ選ぶことはテキストで参照画像を上書きすることに等しい。その項目は丸ごと省き、参照画像に委ねる
- **衝突する項目はそのまま飛ばす**：`appearance`／`styling` のうち参照画像と食い違う部分（髪型、服装のデザイン、色）は省略する。第三の案に「折衷」しない
- **短いほうが正しい**：参照画像モードではディテールの羅列は加点にならず、一つ間違えれば致命傷になる。年齢感・体格・象徴的な特徴で足りる。**服装とアクセサリーは参照画像に委ねる**——特に強調したい細部がある場合のみ書き出す

## 記述順のルール

**最も識別しやすい特徴を前に置き**、この順序で `appearance`（容姿）と `styling`（装い）の各キー要素を漏れなく落とし込む：

1. 識別のアンカー：年齢感（例：「二十歳そこそこ」）、性別感、体格（身長・肥痩、姿勢の癖）
2. 顔立ち：輪郭、目、その他の顕著な特徴（傷跡、ほくろ、眼鏡など）——正面顔クローズアップは特にこの部分の描写に依存する
3. メイクと肌：肌の色と質感、チーク、唇の色とツヤ、アイメイク（ライン／シャドウ／まつげ）、眉の形——正面顔クローズアップの識別性の半分はここで決まる
4. 髪型：色、長さ、スタイル
5. 服装：デザイン、色、素材、レイヤー、状態（例：「袖口にはんだの跡のある皺だらけの作業服」）——一点ずつ書き切り、要約しない
6. アクセサリー：識別性のあるものだけを書き、詰め込まない

キャラクターの性格特性は外的な雰囲気と表情の描写に変換する（例：「憔悴」→「疲れ切った眼差し、肩がわずかに落ちている」）。性格を表す語彙を直接登場させない。

## 構図と一貫性

- 左側の正面顔クローズアップ：正面からカメラに向き、中立的な表情、頭頂から肩まで完全に画面に収める
- 右側の3枚の全身ビュー：同一キャラクターの正面、90度側面、背面。**等高で並び、間隔は均等**、頭頂と足裏が同一水平線上にある
- クローズアップと3枚の全身ビューは同じ顔、同じ髪型、同じ服装でなければならない——「正面顔クローズアップと3枚の全身ビューの顔・髪型・服装は完全に一致」と明確に書き出す
- 中立的な立ち姿、自然な表情——参照画像として再利用しやすくするため
- 柔らかく均一なスタジオ光。劇的な光影は使わない（参照画像はあらゆるシーンで使える必要がある）
- 出力はセッションの言語指令で指定されたターゲット言語を使い、無関係な語彙を混ぜない

## 禁止事項

- 動的なポーズ、誇張された表情、手に持った小道具、他人との共演
- 身体の裁切（全身ビューは必ず full body で頭頂から足裏まで完全に画面に収める；クローズアップは頭部と肩部を完全に画面に収める）
- 文字、ラベル、透かし、署名
- 強い影、カラーの背景光、背景の小道具

## 保存

`save_character_final_prompt` を呼び出す：prompt パラメータにスタイル語を含めない。**プロジェクトのビジュアルスタイルはツールが最終プロンプトの先頭へ自動注入する**。
