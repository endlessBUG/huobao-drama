# 캐릭터 최종 프롬프트(좌측 정면 얼굴 클로즈업 + 우측 삼면도)

생성물은 캐릭터 설정 참조 이미지(character reference sheet)이며, 구도는 다음과 같이 고정됩니다:

- **좌측: 정면 얼굴 클로즈업** — 머리와 어깨의 정면 근경. 이목구비, 헤어스타일, 피부 질감이 선명하게 보이며, 얼굴 식별도의 앵커 역할을 합니다
- **우측: 정면, 90도 측면, 후면의 같은 키 전신 뷰 3장을 나란히 배치** — 같은 캐릭터의 세 가지 전신 뷰를 같은 키로 나란히 놓고, 머리 꼭대기와 발바닥을 정렬합니다

**핵심 원칙: 일관성 > 아름다움.** 이 이미지는 이후 모든 캐릭터 이미지·비디오 참조의 이미지 앵커이므로, 중립적이고 선명하며 재사용 가능해야 합니다 — 단일 이미지의 예술성을 추구하지 마세요.

**참조 이미지가 있으면 참조 이미지가 외모의 기준입니다.** 사용자가 참조 이미지를 업로드했다면 그 이미지 속 인물이 유일한 외모 출처입니다. 프롬프트의 역할은 **가리키기**("참조 이미지와 같은 인물")와 **구도**(삼면도를 어떻게 배치할지)이며, 이 인물을 다시 디자인하는 것이 아닙니다. 실측 결과: 텍스트가 참조 이미지와 충돌하면 출력은 **텍스트를 따릅니다** — 참조 이미지가 흰 사(紗)에 금자수가 있는 선협풍 드레스여도, 텍스트에 "베이지색 실내복"이라고 쓰면 그 얼굴로 베이지색 실내복이 나옵니다. 참조 이미지 모드에서 외모·의상 묘사는 한 문장 한 문장이 참조 이미지와의 **경쟁**이며, 보충이 아닙니다.

## 원래 설정의 충실한 재현(최우선 제약)

캐릭터의 `appearance`(외모)와 `styling`(스타일링)이 곧 그 캐릭터의 원래 설정이며, 사용자가 제공한 참조 이미지나 대본에서 나옵니다. **최종 프롬프트는 원래의 외모와 의상을 항목별로 충실히 옮겨 적어야 하며, 요약·대체·미화·임의 변경을 해서는 안 됩니다** — 삼면도는 파이프라인 전체의 이미지 앵커이므로, 여기서 옷 한 벌을 바꾸면 이후 모든 이미지와 비디오가 그 오류를 물려받습니다.

**우선순위: 참조 이미지 > `appearance` / `styling` 텍스트.** 둘이 일치하면 위 규칙대로 항목별로 옮겨 적고, 충돌하면 참조 이미지를 우선하며 충돌한 항목은 **쓰지 않습니다**(쓰면 텍스트로 참조 이미지를 덮어쓰는 셈입니다). 참조 이미지가 없으면 텍스트가 유일한 출처이므로 전부 적어야 합니다.

- **이목구비 / 헤어스타일**: 얼굴형, 눈매, 눈썹 모양, 머리 길이와 스타일을 하나씩 적으세요. "정교한 이목구비", "긴 머리" 같은 뭉뚱그린 표현으로 압축하지 마세요
- **메이크업 / 피부**: 피부 톤과 질감, 블러셔, 입술 색과 광택, 아이 메이크업(라인 / 섀도 / 속눈썹), 눈썹 모양을 하나씩 적으세요. **가장 자주 빠뜨리는 항목**입니다 — 쓰지 않으면 기본값으로 넘어가 민낯이나 일반적인 진한 화장이 되어, 원래 설정의 입술 색·피부 톤·화장과 어긋납니다
- **의상**: 디자인 + 색상 + 소재 + 레이어(이너 / 겉옷 / 허리띠 등) + 상태를 모두 적으세요. 예: "흰색 반투명 사(紗) 겉옷, 그 안에 흰색 스트랩리스 상의, 가슴 앞 금색 영락, 금색 허리띠" — "흰색 한푸 상의"만 쓰지 마세요
- **액세서리**: 원래 설정에 등장하는 귀걸이·목걸이·머리 장식·이마 장식 등을 하나도 빠뜨리거나 합치지 말고 모두 남기세요
- **창작 금지**: 원래 설정에 없는 디테일을 임의로 추가하지 마세요. 애매하면 원래 표현을 그대로 두고 다른 의상으로 덮어쓰지 마세요

## 출력 구조(이 순서대로 하나의 연결된 문장으로 조립, 언어는 세션 언어 지시를 따름)

**참조 이미지가 있을 때**는 이 버전 — 첫 문장에서 참조 이미지를 외모의 기준으로 고정하고, 슬롯에는 참조 이미지에서 보이는 식별점만 쓰며 항목을 나열하지 않습니다:

```
참조 이미지와 같은 인물을 기준으로 삼는다. 얼굴형·이목구비·헤어스타일·피부 톤·메이크업·의상·액세서리는 모두 참조 이미지 그대로 유지하고, 바뀌는 것은 각도와 구도뿐이다.
캐릭터 설정 참조 이미지. 좌측은 정면 얼굴 클로즈업, 우측은 정면, 90도 측면, 후면의 같은 키 전신 뷰 3장을 나란히 배치.
클로즈업과 전신 뷰는 모두 같은 캐릭터이며, 전신이 화면에 들어오고, 중립적인 A자 서기 자세. 세 가지 전신 뷰는 같은 키로 나란히 놓고 머리 꼭대기와 발바닥을 정렬.
[참조 이미지에서 실제로 보이면서 강조할 가치가 있는 식별점만: 나이대 + 체형 + 상징적인 이목구비 / 헤어스타일 / 의상 요점].
정면 얼굴 클로즈업과 세 가지 뷰의 얼굴, 헤어스타일, 의상이 완전히 동일. 메이크업과 액세서리도 마찬가지로 동일하며, 참조 이미지와 같은 인물이다.
순백 배경, 부드럽고 고른 조명, 영화적 질감
```

**참조 이미지가 없을 때**는 이 버전 — 텍스트가 유일한 출처이므로 슬롯을 모두 적어야 합니다:

```
캐릭터 설정 참조 이미지. 좌측은 정면 얼굴 클로즈업, 우측은 정면, 90도 측면, 후면의 같은 키 전신 뷰 3장을 나란히 배치.
클로즈업과 전신 뷰는 모두 같은 캐릭터이며, 전신이 화면에 들어오고, 중립적인 A자 서기 자세. 세 가지 전신 뷰는 같은 키로 나란히 놓고 머리 꼭대기와 발바닥을 정렬.
[나이대 + 성별감 + 체형], [이목구비 특징], [메이크업과 피부], [헤어스타일].
[의상: 디자인 + 색상 + 소재 + 레이어 + 상태], [액세서리: 하나씩 나열하고 합치지 않음].
정면 얼굴 클로즈업과 세 가지 뷰의 얼굴, 헤어스타일, 의상이 완전히 동일. 메이크업과 액세서리도 마찬가지로 동일.
순백 배경, 부드럽고 고른 조명, 영화적 질감
```

## 참조 이미지 모드 규칙(사용자가 참조 이미지를 업로드한 경우)

참조 이미지는 이미 그 인물의 외모 정보를 모두 담고 있습니다. 텍스트의 역할은 **그것을 덮지 않는 것**입니다:

- **참조 이미지에서 보이는 것만 쓰기**: 슬롯의 각 항목은 참조 이미지 위에서 가리킬 수 있어야 합니다. 참조 이미지에 없는 디자인·색상·헤어스타일은 쓰지 않습니다
- **선택지에서 고르지 않기**: 원래 설정에 "또는 / 예를 들어 / 어느 쪽이든" 같은 선택 표현이 있을 때(예: "부드럽게 몸에 붙는 실내복, 색은 따뜻한 계열(예: 베이지, 연분홍 또는 짙은 회색)")에는 **그중 하나를 골라 못 박지 마세요** — 하나를 고르는 것은 텍스트로 참조 이미지를 덮어쓰는 것과 같습니다. 그 항목은 통째로 생략하고 참조 이미지에 맡기세요
- **충돌 항목은 그냥 건너뛰기**: `appearance` / `styling` 중 참조 이미지와 어긋나는 부분(헤어스타일, 의상 디자인, 색상)은 생략합니다. 제3의 안으로 "절충"하지 마세요
- **짧은 쪽이 옳다**: 참조 이미지 모드에서 디테일 나열은 가점이 되지 않고, 하나 틀리면 치명적입니다. 나이대·체형·상징적 특징이면 충분하며, **의상과 액세서리는 참조 이미지에 맡기세요** — 반드시 강조할 세부가 있을 때만 적습니다

## 묘사 순서 규칙

**가장 식별도가 높은 특징을 앞에 배치**하고, 이 순서대로 `appearance`(외모)와 `styling`(스타일링)의 모든 핵심 요소를 누락 없이 구체화합니다:

1. 정체성 앵커: 나이대(예: "스물 초반"), 성별감, 체형(키와 몸매, 자세 습관)
2. 이목구비: 얼굴형, 눈, 기타 뚜렷한 특징(흉터, 점, 안경 등) — 정면 얼굴 클로즈업이 특히 이 부분 묘사에 의존합니다
3. 메이크업과 피부: 피부 톤과 질감, 블러셔, 입술 색과 광택, 아이 메이크업(라인 / 섀도 / 속눈썹), 눈썹 모양 — 정면 클로즈업 식별도의 절반은 여기서 나옵니다
4. 헤어스타일: 색상, 길이, 스타일
5. 의상: 디자인, 색상, 소재, 레이어, 상태(예: "소매에 납땜 자국이 있는 구겨진 작업복") — 한 벌씩 모두 적고 요약하지 마세요
6. 액세서리: 식별도가 있는 것만 쓰고, 잔뜩 쌓지 마세요

캐릭터의 성격 특징은 외적인 분위기와 표정 묘사로 전환합니다(예: "초췌함" → "피로한 눈빛, 살짝 처진 어깨"). 성격 단어를 직접 쓰지 마세요.

## 구도와 일관성

- 좌측 정면 얼굴 클로즈업: 카메라를 정면으로 향하고, 중립적인 표정, 머리 꼭대기부터 어깨까지 완전히 화면에 들어옴
- 우측 세 가지 전신 뷰: 같은 캐릭터의 정면, 90도 측면, 후면. **같은 키로 나란히, 간격 균일**, 머리 꼭대기와 발바닥이 같은 수평선 위에 있음
- 클로즈업과 세 가지 전신 뷰는 반드시 같은 얼굴, 같은 헤어스타일, 같은 의상이어야 합니다 — "정면 얼굴 클로즈업과 세 가지 전신 뷰의 얼굴, 헤어스타일, 의상이 완전히 동일"하다고 명시적으로 쓰세요
- 중립적인 서기 자세, 자연스러운 표정 — 참조 이미지로 재사용하기 좋게 합니다
- 부드럽고 고른 스튜디오 조명, 극적인 명암 금지(참조 이미지는 어떤 장면에서도 쓸 수 있어야 함)
- 출력은 세션 언어 지시가 지정한 목표 언어를 사용하고, 무관한 어휘를 섞지 마세요

## 금지 사항

- 역동적인 포즈, 과장된 표정, 소품을 손에 든 모습, 다른 사람과 함께 등장
- 신체 잘림(전신 뷰는 반드시 full body로 머리 꼭대기부터 발바닥까지 완전히 화면에 들어와야 함; 클로즈업은 머리와 어깨가 완전히 들어와야 함)
- 텍스트, 라벨, 워터마크, 서명
- 짙은 그림자, 컬러 배경광, 배경 소품

삼면도의 레이아웃은 **전적으로** 이 문장들에서 나옵니다. 생략했을 때의 결과는 실측했습니다: 스타일 단어 + 참조 이미지만 주면 모델이 실행할 레이아웃이 없어 참조 이미지를 그대로 한 장의 인물화로 다시 그립니다.

`appearance`(외모) / `styling`(메이크업·의상) 원문 텍스트의 최적화를 요청받은 경우: 아래 "묘사 순서 규칙"에 따라 항목별로 다시 쓰고, 사용자가 정한 사실은 유지하며, 새로운 설정을 만들어내지 않습니다.
