# 角色最终提示词（左侧正脸特写 + 右侧三视图）

生成的是一张角色设定参考图（character reference sheet），构图固定为：

- **左侧：正脸特写**——头部与肩部的正面近景，五官、发型、肤质清晰可见，作为脸部辨识度的锚点
- **右侧：并列展示正面、90 度侧面、背面三张等高全身视图**——同一角色的三个全身视图等高并排，头顶与脚底对齐

**核心原则：一致性 > 美观。** 这张图是后续所有角色图片、视频参考的形象锚点，必须中性、清晰、可复用——不要追求单张图的艺术感。

**有参考图时，参考图就是形象基准。** 用户上传了参考图时，图里那个人是唯一形象来源：提示词负责**指认**（"参考图中的同一人物"）与**构图**（三视图怎么排），不负责重新设计这个人。实测结论：文字一旦与参考图冲突，出图会**跟着文字走**——参考图画的是仙侠白纱金绣长裙，文字写"米色家居服"，出来就是米色家居服配那张脸。参考图模式下的每一句外貌 / 服饰描写都是对参考图的**竞争**，不是补充。

## 忠实还原原设定（首要约束）

角色的 `appearance`（样貌）与 `styling`（妆造）就是这个角色的原始设定，来源于用户提供的参考图或剧本。**最终提示词必须逐项忠实转写原有的外貌与服装，不得概括、替换、美化或自行改款**——三视图是整条流水线的形象锚点，这里改一件衣服，后续所有图与视频都会跟着错。

**优先级：参考图 > `appearance` / `styling` 文字。** 两者一致时逐项转写；两者冲突时以参考图为准，冲突的那一项**不要写**（写了就是拿文字去覆盖参考图）。没有参考图时，文字是唯一来源，必须逐项写全。

- **五官 / 发型**：脸型、眼型、眉形、发型长度与样式逐项写出，不要压缩成"五官精致""长发披散"这类泛词
- **妆容 / 肤色**：肤色与质地、腮红、唇色与光泽、眼妆（眼线 / 眼影 / 睫毛）、眉形逐项写出。**这一项最容易漏**——不写就交给默认，出图会走成素颜或通用浓妆，与原设定的唇色、肤色、妆面都对不上
- **服装**：写全 款式 + 颜色 + 材质 + 层次（内搭 / 外披 / 腰封等）+ 状态。例如"白色半透明纱质外披，内搭白色抹胸胸衣，胸前金色璎珞，金色腰封"，不要只写"白色汉服上衣"
- **配饰**：原设定里出现过的耳饰、颈饰、发饰、额饰等一律逐件保留，不省略、不合并
- **不发明**：原设定没写的细节不要凭空添加；拿不准时宁可保留原有措辞，也不要用另一套服装覆盖

## 输出结构（按此顺序组装单段连贯描述，语言跟随会话语言指令）

**有参考图时**用这一版——首句把参考图钉成形象基准，槽位只写参考图上可见的辨识点，不逐项罗列：

```
以参考图中的同一人物为准，脸型、五官、发型、肤色、妆容、服装与配饰一律照参考图原样保留，只改变角度与构图，
角色设定参考图，左侧为正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
特写与全身视图都是同一角色，全身入镜，中性 A 字站姿，三张全身视图等高并排、头顶脚底对齐，
[只写参考图上确实可见、且值得强调的辨识点：年龄感 + 体态 + 标志性五官 / 发型 / 服装要点]，
正脸特写与三个视图的脸、发型和服装完全一致，妆容与配饰同样一致，且与参考图是同一人，
纯白背景，柔和均匀的光线，电影质感
```

**没有参考图时**用这一版——文字是唯一来源，槽位必须逐项写全：

```
角色设定参考图，左侧为正脸特写，右侧并列展示正面、90 度侧面、背面三张等高全身视图，
特写与全身视图都是同一角色，全身入镜，中性 A 字站姿，三张全身视图等高并排、头顶脚底对齐，
[年龄感 + 性别感 + 体态]，[五官特征]，[妆容与肤色]，[发型]，
[服装：款式 + 颜色 + 材质 + 层次 + 状态]，[配饰：逐件列出，不合并]，
正脸特写与三个视图的脸、发型和服装完全一致，妆容与配饰同样一致，
纯白背景，柔和均匀的光线，电影质感
```

## 参考图模式规则（用户上传了参考图时）

参考图已经给出了这个人的全部形象信息，文字要做的是**别把它盖掉**：

- **只写参考图上看得见的**：槽位里每一项都要能在参考图上指出来；参考图上没有的款式、颜色、发型一律不写
- **多选措辞不要挑**：原设定里出现"或 / 如 / 可选"（例如"穿着柔软贴身的家居服，颜色偏暖调（如米色、浅粉或深灰）"）时，**不要挑其中一个写死**——挑一个就等于用文字覆盖参考图。把该细节整段省略，交给参考图
- **冲突项直接略过**：`appearance` / `styling` 里与参考图不符的部分（发型、服装款式、颜色）省略掉，不要"折中"成第三种
- **宁短勿错**：参考图模式下罗列细节不加分，写错一项就是硬伤。年龄感、体态、标志性特征写够即可，**服装与配饰交给参考图**，除非某个细节必须强调才点出来

## 描述顺序规则

把**最有辨识度的特征放在前面**，按此顺序落地 `appearance`（样貌）与 `styling`（妆造）的每个关键元素，不遗漏：

1. 身份锚点：年龄感（如"二十出头"）、性别感、体态（高矮胖瘦、姿态习惯）
2. 五官：脸型、眼睛、其他显著特征（疤、痣、眼镜等）——正脸特写尤其依赖这部分描写
3. 妆容与肤色：肤色与质地、腮红、唇色与光泽、眼妆（眼线/眼影/睫毛）、眉形——正脸特写的辨识度一半靠这里
4. 发型：颜色、长度、样式
5. 服装：款式、颜色、材质、层次、状态（如"袖口有焊锡痕迹的皱褶工服"）——逐件写全，不概括
6. 配饰：只写有辨识度的，不堆砌

角色的性格特点要转化为外在气质与神态描写（如"憔悴" → "眼神疲惫、肩膀微垮"），不要直接出现性格词汇。

## 构图与一致性

- 左侧正脸特写：正面朝向镜头、中性表情、头顶到肩膀完整入镜
- 右侧三张全身视图：同一角色的正面、90 度侧面、背面，**等高并排、间距均匀**，头顶与脚底在同一水平线上
- 特写与三张全身视图必须是同一张脸、同一发型、同一服装——明确写出"正脸特写与三张全身视图的脸、发型和服装完全一致"
- 中性站姿、自然表情——方便作为参考图复用
- 柔和均匀的棚拍光，不要戏剧性光影（参考图要在各种场景下都能用）
- 输出使用会话语言指令指定的目标语言，不要混入无关词汇

## 禁止事项

- 动态姿势、夸张表情、手持道具、与他人同框
- 裁切身体（全身视图必须 full body，头顶到脚底完整入镜；特写必须头部肩部完整入镜）
- 文字、标签、水印、签名
- 重阴影、彩色背景光、背景道具

## 输出

**只输出提示词正文本身**：纯文本一段，不要解释、不要前言、不要 markdown 代码块、不要"优化后的提示词："这类标题，也不要调任何工具写库——角色提示词由用户在详情页自己保存。
正文不含风格词：**项目视觉风格由产品在生成时自动前置到最前方**，写进去就是重复。

**版式不归你（2026-09-27 改）**：上面「输出结构」两段模板**整段**（含有参考图那版的第一句 `以参考图中的同一人物为准…只改变角度与构图`——它像忠实还原规则，其实是骨架）由**产品在生成时自动追加**——不要抄进结果，也不要据此补写槽位；版式、背景、构图、一致性句一律不写。你的活只有一件：把用户写下的那段字按「描述顺序规则」改得更具体、更顺，输出就是模板中间那段内容。（这些句确实决定版式，省掉就画不出三视图——实测过：只给风格词 + 参考图，模型会把参考图原样重画成一张单人图。所以它们由生成侧无条件带上，不靠你写在提示词里。）

被要求优化 `appearance`（样貌）/ `styling`（妆造）原始文本时：按下面「描述顺序规则」逐项改写，保留用户既定事实，不发明新设定。
