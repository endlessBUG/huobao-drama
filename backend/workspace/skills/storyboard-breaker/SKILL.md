# 分镜拆解指南

## 核心定义：分镜段落

一个分镜 = 一个 **分镜段落**（segment）= 一个视频生成任务。

- 每个段落时长 **8-15 秒**，内部承载 **2-3 个子镜头**（8-12 秒默认 2 个，12-15 秒最多 3 个）。子镜头越多成片切得越碎：4 个以上等于每 3 秒一刀，同一场景里就是「切来切去」
- 子镜头之间**可以切镜**，用硬切衔接。但切镜有**准入条件**：必须引入新信息——新主体、新空间、新状态、新视角或新时间（MiniMax H3 官方 §4.2 口径）。**只想把景别推近／拉远、或轻微换个角度，不要切镜，写成运镜**：「中景 → 特写」是一条推镜，不是切一刀。同一主体、同一空间、同一时间点上反复切景别，成片就是没有信息量的跳来跳去；同一组人物的**中近景 ↔ 双人中近景 / 正反打**也属于同一镜的距离变化，用推镜/拉镜，不切
- 子镜头之间**不跨场景**：一个段落只发生在一个场景内（`scene_id` 是段落级绑定）
- 每个子镜头 2-6 秒，聚焦一个画面单元（一个动作、一个反应、一个特写）

## 拆分流程（四步）

1. 调用 `read_storyboard_context` 读取剧本、角色、场景、道具、已有分镜摘要
2. **节拍识别**：先识别剧本的叙事节拍——剧本中的【开场】【触发】【高潮】【收尾】等标记，或叙事转折点（地点转移、规则揭示、情绪爆发、反转）。**节拍边界强制切段**，同一节拍内的子镜头优先归入同一段落，不把一条因果链（铺垫-发生-反应）切散到不同段落
3. **总量锚定**：目标总时长 = 剧本字数 ÷ 500字/分钟；段落数 ≈ 目标总时长 ÷ 12秒，允许 ±20% 浮动。不要明显超出或不足。**段落数不许超过剧本能提供的独立节拍数（硬规则，1019 实测）**：节拍用完还继续凑，模型就开始复读——实测第 11 段起把「影子合一 / 薄被无人拉」交替抄了 6 遍，标题里甚至出现「无人拉」这种没有施动者的反模式名。宁可少写几段，也不要重复段落凑时长
4. **段落内拆子镜头**：按动作切换点、视角切换点、对象切换点切分子镜头，为每个段落补全完整字段后调用 `save_storyboards` 保存。**分批保存（硬规则）**：每次调用最多 8 段——第一批带 `replace_existing: true`（清掉整集旧分镜再写），之后每批**省略** `replace_existing`（追加）。一次塞 16 段会被输出上限截断、工具调用根本没生成，表现为「跑完了但没落库」（1019 实测：4 段能存、16 段直接停在省略号）。按 `shot_number` upsert，重发同批不会产生重复行

## 节奏分层时长

按段落功能确定时长，不要一刀切：

| 段落类型 | 时长 | 说明 |
|---|---|---|
| 过渡段 | 8-10 秒 | 赶路、空镜、环境建立、转场 |
| 叙事段 | 10-15 秒 | 常规剧情推进、对话 |
| 爆点段 | 12-15 秒 | 特写、规则揭示、情感爆发、反转；子镜头节奏放慢，单个子镜头可停留 4-6 秒 |

## 台词时长下限（硬规则）

**段落时长 ≥ 段内台词与旁白总字数（写在 description 中的部分）÷ 4.5字/秒 + 2秒表演余量**

装不下的台词必须拆到下一个段落，不允许把演不完的台词塞进一个段落。

## 镜头要素

1. **镜头标题**：3-5字概括段落核心内容（如"噩梦惊醒"）
2. **时间**：具体时分 + 光线描述
3. **地点**：场景完整描述 + 空间布局 + 环境细节
4. **景别**：段落内主导景别；多景别段落写组合，如"中景+特写"
5. **角度**：平视/仰视/俯视/侧面/背面
6. **运镜**：固定/推镜/拉镜/摇镜/跟镜/移镜（段落内不同子镜头可不同）。**只改景别或轻微角度时用运镜，不要切镜**——这条与视频提示词侧的官方机位词（`Static` / `Push In` / `Pull Out` / `Pan` / `Truck` / `Tracking` 等）一一对应
7. **画面描述** `description`：按 `【镜头1】…【镜头2】…` 逐子镜头描述观众实际看到和听到的内容——画面（谁 + 在画面哪一侧 + 具体动作 + 肢体细节 + 表情）写在前；该子镜头有台词时以「角色名说：「台词」」写在对应 `【镜头N】` 内，旁白写「旁白：内容」。每个【镜头N】按**五要素**写全：① 动作/姿态/表情 ② 机位/景别/运镜 ③ 画面位置（哪一侧、相对哪件陈设、朝向）④ 声音（对白/环境音）⑤ **末态**（这一镜结束时的手位、持物、视线、接触点），供下一镜/下一段承接
8. **画面结果** `result`：段落结尾的即时后果 + 视觉细节
9. **氛围** `atmosphere`：光线 + 色调 + 声音 + 整体氛围
10. **时长** `duration`：段落总时长 8-15 秒，且满足台词时长下限
11. **场景关联**：若能匹配已有场景，必须填写 `scene_id`
12. **衔接** `continuity`：与**上一段**的关系。同一个镜头被切成两段（同机位、同景别、同空间连续）写 `same_shot`；引入新信息（新主体、新空间、新状态、新视角、新时间——即上面 §4.2 的切镜准入）写 `cut`。每集第一段写 `same_shot`（没有上一段）。这条决定生成时怎么接：`same_shot` 且同场景 → 上一段尾帧既当参考也锚在第 0 帧；`cut` 且同场景 → 只当参考（追光照和色调，不追机位）；跨场景 → 不带尾帧
12. **角色关联**：填写 `character_ids`，绑定当前段落涉及的 0 到多个角色
13. **道具关联**：填写 `prop_ids`，绑定当前段落出现的关键道具（0 到多个）

## 空间与走位（硬规则）

每个分镜段落是**独立生成的一条视频**，模型每次调用都没有上一段的记忆。空间不写下来，每条都会自己重摆一遍——拼起来就是人物左右横跳、道具乱飘（实测同一场戏里两条视频能把两个人摆反）。空间必须当成**写下来才存在**的事实：

- **空间锚点**：某个场景第一次出现时，把固定陈设的相对位置一次写死（床/桌/窗/门/灯在画面的哪一侧、前景还是背景），只能用该场景已有的陈设，不要发明新家具；同一场景的后续段落沿用同一套，不许改
- **角色站位**：每个角色在该场景里有一个固定站位，写成「**相对哪个固定陈设** ＋ 画面左/右 ＋ 前景/背景 ＋ 朝向」，如「女生A 在画面左侧、床头灯那一侧的床沿，面朝右」。**两样都要写**：画面左右是这一镜的事实，相对陈设是换机位也不变的事实（切成正反打，左右会翻，「床头灯那一侧」不会翻）。同一个场景内跨段落恒定：没写他移动，位置、朝向、依托物就不得变
- **逐镜复述**：每个 `【镜头N】` 都要写清这一镜里谁在哪、看谁、手停在哪；切镜后重新交代一次站位，不要写「同上」「不变」
- **移动要有可见过程**：从坐到站、从桌前到门口、转身离场，都要写出动作过程，没写过程就不许换位置；段末离场的人再入画，要写明入画方式（如「自画面左侧门口走入，回到床沿」）
- **物体位移也要有施动者（1018 实测）**：被子、门、抽屉、杯子这类物体自己移动，模型就画成它凭空自己动（写「薄被从床榻外侧滑落」→ 成片薄被没有手去掀、自己滑下去）。物体位置变化必须点名施动者：谁的手或身体做的、从哪到哪、经过什么（如「女生A 的右手把薄被从自己腰上往下拉，布料滑过她大腿外侧、堆到床垫上」）
- **每个子镜头都要有可见动作（1018 实测）**：纯光线、烛火、影子、烟雾的变化撑不起一个子镜头（连续两段写「各自撑躺姿态不变、烛火变矮」→ 模型没有动作可跟，自己加小动作，人物显得随意）。每个 `【镜头N】` 至少推进一个身体/手/物件的可见变化，光线变化只能挂在有动作的子镜头里
- **视线指派**：有台词的子镜头写明说话人看向谁，否则模型会让他看镜头或看道具
- **表情逐镜写（1018 用户「人物也需要有表情描述」）**：每个 `【镜头N】` 都要写脸上**可见**的表情变化——咬唇/抿唇松开、眯眼蹙眉、嘴角歪起、脸红到耳根、眼神失焦、仰头闷哼、呼吸变重——与身体动作同步；亲密镜头里表情就是画面信息主体，不许整条只有身体动作没有脸。表情写**过程**（从抿唇到咬唇），不写「很开心/很紧张/很享受」这类标签词
- **只写位置，不写造型**：服装、发型、妆容、配饰一律不写——这些由角色参考图决定，编出来必然跟角色图打架（角色长什么样不归分镜管）
- 空间用**正面陈述**（「在画面左」），不要用否定句（「不要换到右边」）——采样没有负面分支，否定句不起作用

## 镜头职责与切镜（导演口径，社区专业分镜表蒸馏）

出处：zenstory-ai/drama-skills `short-drama-storyboard`（SHT 规则表）与 eternityspring/shuohao-skills `novel-storyboard`。与「切镜准入」并列，都是硬规则：

- **一镜一职责**：每个【镜头N】只干一件事——建立空间 / 推进动作 / 给反应 / 给证据特写 / 转情绪。写不出「这一镜给观众什么」就不要它（镜头目的五问：给谁看、看什么、为什么现在看、看完知道什么、怎么接下一镜）
- **工作景别**：一场戏先宽一档定空间（全景/中景），第二镜落到**工作景别**（这场戏绝大多数信息发生的景别，对话/亲密场 = 近景或中近景），后续镜头在工作景别上小幅来回；宽景别与特写都是**标记事件**，用过必须回到工作景别，不许整场漂在两个极端
- **切点必须带来可见变化**：同景别＋同角度＋同一人物关系再切一刀 = 无信息跳切（成片「切来切去」的根源）。每一刀要么换景别档、要么换主体、要么换空间、要么推进时间
- **动作落实表**：一个动作只有一个**主要落实镜头**——前一镜的末态不许提前出现在后一镜开头，后一镜不许重演上一镜已完成的动作；同一冲击（门被撞开、杯子摔碎）要重复必须声明「同一事件的另一角度」
- **反应落点（互动双方都要写，1018 用户「如果是互动 要描写互动双方的反应」）**：互动镜头必须写**施动者的动作 + 受动者的可见接收反应**（被碰到的人的眼神变化、呼吸变重、身体绷紧或往后躲、手指收紧）。反应是免费的戏：重台词、关键接触之后切听者/受动者的脸 2-3 秒，比继续拍说话人信息量大
- **建立镜头自己挣位置**：开场空间建立镜必须承载剧情（有人在动、有事在发生），纯空镜撑不起开场；观众还不知道在哪时，第一切给运动主体
- **镜长从声音事件时间线来**：先排台词/动作音的秒数，再定【镜头N】边界；台词装不下的镜拆成说话者镜 + 听者反应镜，语速不许变
- **节奏（短剧呼吸）**：3 秒一刀是呼吸单位，但**均匀病判死**——每刀都是 3 秒中景、景别不深浅相间、时长不长短相间，成片像幻灯片；关键动作独立成切（insert 特写 = 节奏重音）；段的最后一刀留钩（未完成的动作、未回答的视线）
- **动接动**：切点选在动作进行中而不是动作完成后（上一镜手抬到一半切，下一镜从一半接）；跨段承接时末态写到动作中途

## 轴线与机位（硬规则）

- **左右读法**：裸写「在画面左/右」= 观众视角；人物自身肢体必须带主体（「他的左手」「她的右手」），两套不许混
- **轴线三行**：两人对话/互动的机位第一次落定前写三行——① 轴线（两人视线连线）↔ 锚点（相对哪件陈设）② working side（摄影机在轴线哪一侧）③ 屏幕方向（谁在画面左）。同场后续所有机位留在同一侧；**要越轴必须重新声明**（写明「机位换到轴线另一侧，左右互换」），不许无声越轴
- **正反打配对**：反打写「谁的肩在前景」（过肩写谁的肩）、屏幕方向互补（A 朝右说话 → B 反打朝左听）、视线高度按两人身高差（坐/站/卧要写谁高谁低）；对称构图 = 两人势均力敌，不对称 = 一方占优，按剧情选
- **角度三栏**：每个【镜头N】写全 水平角度（正面/侧面/背面/斜侧）＋ 机位高度（平视/仰/俯）＋ 焦段意图（广角贴脸、长焦压缩背景）。仰拍≠正面、俯拍≠过肩，三个维度各自独立

## 导演层（关键场才做，普通场直接拆）

爆点场/转折场在拆【镜头N】之前先做两件事（过渡场跳过，别为每场都烧一遍）：

- **七轴视觉计划**：这一场的画面由导演一次统一决定——光（方向/硬度/色温）、色（主色/对比）、景别曲线（从哪档到哪档）、机位高度曲线、运动曲线（从哪一步开始动）、纵深（前景遮挡/中景人物/背景陈设）、构图（对称/三分/框中框）。七轴写进 `atmosphere` 与 `description`，让整场像一个导演的手笔，不是逐镜各摆
- **五命题覆盖比较**：这场要传达的五个事实逐条问「观众从哪个镜头拿到」——空间关系、人物关系、关键动作、关键证据（物件特写）、情绪落点。没有任何镜头给 = 补一个特写/反应镜；两个镜头都给 = 删掉弱的那个
- **群戏关系投影**：三人以上同框，用站位把权力关系画出来（谁居中、谁背对谁、谁在景深处），给每人一个可见的朝向与视线落点；说话时切听者反应（见「反应落点」）
- **交付面遮挡**：要观众看清的东西（脸、手、物件、信件内容）必须无遮挡入画；被挡着就切到能看清的机位，不许「挡着但观众知道它在」
- **首帧 = 可冻结瞬间**：`image_prompt`（首帧图）画这一镜**开始前**的状态——不带本镜运动才产生的结果（推镜的首帧不写「已贴近」、起身的首帧不写「已站着」）；落笔前自检六项齐：景别、人数、站位、姿态、光向、遮挡

## 肢体接触（硬规则）

肢体接触是最容易穿模的地方（1018 实测：写「双腿缠上腰间」→ 腿穿进躯干）。接触必须写成**点对点的表面接触**，不能写成连续重叠：

- **并躺/侧躺时禁止写腿部接触（1018 两次实测）**：不写「腿缠腰」「腿贴髋」「双腿夹住」——一条腿要碰到对侧髋必须跨过对方身体中线，模型算不出这条腿的髋关节，实测必穿模。分镜里直接写**上半身动作**（手扣手腕、掌心贴肩/后颈、指尖停在发际线）；腿部最多写「脚踩在自己一侧床面」这种落点，且该镜头默认腰部以上景别、腿不入画。
- **只写接触点**：谁的哪个部位贴住对方的哪个部位、接触的是外侧/衣物表面（如「右手掌贴住对方左肩外侧」）。不写「陷进/穿过/进入对方身体」
- **禁止缠绕措辞**：「缠在腰间」「双腿锁住」「绕住」会让模型把肢体塞进躯干；改成「贴住/压住/搭在/握住」
- **写清承重点和另一条肢体**：重量落在床面/椅面/地面；另一只手在哪（「左手仍撑在床垫上」）
- **接触是状态不是动词**：进入/退出接触都要写可见过程（抬起→贴近→贴住），一个子镜头只写一个因果动作，不要又抱又翻身又换位
- **逐镜复述**：同一段落相邻子镜头、相邻段落的接触点要复述，不许无声换肢体或换接触面
- 仍用**正面陈述**，不写「不要穿模」这类否定句（采样没有负面分支）

## 姿势与关节（硬规则）

一条视频是一次独立采样，上一镜的肌肉记忆不存在；姿态不写下来，模型自己补，补出来的姿态再叠上动作，关节就会拧到物理上做不到的角度。每个有人物的子镜头把下面几件事写成事实：

- **躯干姿态与承重点**：卧（俯卧 / 仰卧 / 侧卧）、坐、站、跪、半撑、倚靠，重量落在哪（地面 / 家具 / 手臂 / 墙）。只写「躺在床上」不够——俯卧、侧卧、半撑的头部与四肢可达范围完全不同
- **头相对躯干的朝向**：脸朝哪一侧、相对躯干转多少。可写范围 0–90°（正面 → 侧脸）；脸朝自己的后背方向是物理上做不到的。人要看身后或脚侧的对象时，先写可见的翻身、转身或改成侧卧，不要只写扭头
- **四肢与接触**：每个接触写清双方的接触部位和接触面；没有参与动作的肢体写明落点（撑在哪、搭在哪、垂在哪），不要留空让模型自己补
- **近距离的头部动作（耳边呼吸 / 低语 / 贴面 / 亲吻等）**：两人的头部相对位置必须与躯干姿态相容——靠近的一方从对方头侧接近，或两人面对面侧卧 / 一坐一卧且上身朝向对方；把两人躯干朝向和头朝向一起写，不要只写「唇贴近耳朵」而不管两个人怎么躺着
- **一个子镜头一次姿态变化**：先写摆好姿势的过程（翻身、撑起、转身、坐下），再写这一镜的动作；同一个子镜头里又翻身又转头又抬手，模型只能挑一个算对
- **大角度转头配固定机位**：头相对躯干转 ≥45° 的子镜头写固定镜头；转头与环绕 / 推拉同镜叠加时，模型会把头和身体一起转
- **一个子镜头一个精准接触**：接触越多、自由度越多，关节崩坏与穿模的概率越高
- 仍用**正面陈述**（「A 侧卧、面朝 B」），否定句不起作用

## 场景关联规则

- 优先使用 `read_storyboard_context` 返回的 `scenes`
- `location + time` 可明确匹配时，必须回填正确 `scene_id`
- 不要凭空生成不存在的场景 ID
- 如果剧本内容明显落在已有场景中，不要重复创造新场景描述

## 角色绑定规则

- `character_ids` 必须从 `read_storyboard_context` 返回的角色列表中选择
- 一个段落可以没有角色，也可以绑定多个角色
- 只要段落里有明确出场、被看见、发生动作或说话的角色，都应绑定进去
- 纯环境段落、空镜、物件特写可以传空数组

## 道具绑定规则

- `prop_ids` 必须从 `read_storyboard_context` 返回的道具列表（`props`）中选择
- 道具被角色使用、交接、特写，或在画面中明显可见且对叙事有意义时，必须绑定到该段落
- 道具特写段落（无角色）也应绑定道具，`character_ids` 可为空
- 与剧情无关的背景物品、场景陈设不要绑定；没有道具出现的段落传空数组
- 绑定的道具会作为视频生成的参考图（白底单品图），保证道具外观跨段落一致

## 质量要求

- `description` 要适合人读，按子镜头详细描述观众实际看到和听到的内容；台词/旁白直接写在对应 `【镜头N】` 内
- `image_prompt` 要突出单帧构图、角色外观、环境和光线（对应段落第一个子镜头）
- `bgm_prompt` 和 `sound_effect` 用简洁短语即可，但不能空泛到只有“紧张”“悲伤”
- 如需调整，调用 `update_storyboard` 修改具体段落——**只改分镜字段（description/atmosphere/image_prompt 等），不许碰 `video_prompt` / `video_prompt_full_ref`**（那是下一步提示词生成管的；1019 实测：拆镜 agent 保存完又逐段 update_storyboards 去「修 full_ref」，17 次调用白烧，且它看不到参考图、改不出正确的六段式）。整集保存用一次 `save_storyboards`（分批、每批 ≤8），不要用 `update_storyboard` 逐段补写
