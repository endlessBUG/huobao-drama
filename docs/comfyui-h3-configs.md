## 当前最优（2026-10-25）

### 1025 定案：零 LoRA 治抖动（`--cpu-vae` 判死）

**抖动真因 = 分镜 `lora_key` 自动挂的 LoRA 绕过 `no_lora:true`。** `no_lora` 只摘桥的 4 步 turbo 节点（`_wf_video_native` 的 `if turbo`），1019 恢复的分镜 LoRA 透传仍会把 `skin_realism` 挂进生产图 ⇒ 静态镜头整屏纹理蠕动。清空 storyboard 255/256 的 `lora_key`、同镜重发：逐帧 MAD **5.44（task 674，挂 `skin_realism`）→ 2.65（task 677，零 LoRA，旧尺口径）**。零 LoRA 的 677 用现役尺（`data/generated/.jit.cjs`，512×384 灰度全帧、294 帧）复测 = **mad_mean 5.82 / p50 6.02 / p95 10.8 / 高频 643.9**。**生产口径：只有露解剖的镜带 `lora_key`，其余镜必须为空**（`no_lora:true` 不等于「不挂分镜 LoRA」，两件事）。

**「每步很慢」= 显存过载，不是 PDD、不是盘（1025 实测）。**
- task 680（native、`--reserve-vram 1.5`、GPU TE + GPU VAE）：步 44/42/45 → **162/279/99 s/步**；GPU 100% util 但只有 42-46 W、盘 100% 空闲、页面文件占用低 ⇒ 卡在权重搬运，不是算力也不是 IO。
- 装载行 `loaded partially; 0.00 MB usable, 0.00 MB loaded, 11945.45 MB offloaded` ⇒ unet 全在内存/盘，每步搬 11.9 GB。
- **`--cpu-vae` 判死（1025 18:5x）**：它治住了爬坡 —— task 681 步 1-9 = 41.78 / 40.59 / 40.25 / 40.15 / 40.02 / 39.94 / 39.87 / 39.83、task 682 = 40.10 / 39.86 / 39.79 / 39.72 / 39.70 … 20 步全程 ≈40 s；**但 H3 视频 VAE 解码直接崩**：682 采样 20/20 走完后在 `VAEDecode`（节点 13）抛 `q, k, and v must be on the same CUDA device`，栈 = `comfy/ldm/minimax/vae.py:315` → `comfy_kitchen/sage_attention.py:550` 的 int8 注意力（H3 VAE 是 int8 解码器，那条路只认 CUDA，CPU 侧没有 fallback）。⇒ 自启参数**回到 677 那份（`--reserve-vram 1.5`、VAE 留 GPU）**，`--cpu-vae` 只作「步时爬坡」的对照组留着。
- 677 = 目前唯一跑完的零 LoRA 294 帧整条：06:51:40Z 发车 → 07:08:12Z completed（**16 分 32 秒**，含装载 + 20 步 + 解码 + 回传）。680 那种 44→162/279/99 的爬坡是**间歇的**（同参数 677 没出事），**未归因**；再遇到先按「GPU 100% util 但 42-46 W + 盘全闲」这条判据认，不要先怀疑盘/内存。
- **常驻还是没拿到**：`get_free_memory = mem_free_cuda + (reserved − active)`（`model_management.py:1849-1854`），unet 装载时算出 ≈0 ⇒ TE 那 14.8 GB 没回到池里（否则 15.5 GB 空闲足够装 11.9 GB）。候选根因 = `[huobao-1013]/[huobao-1015]` 的 `skip_model_to=True`（`model_patcher.py:1318` → `unpatch_model` 的 `:1163`）跳过 `.to(cpu)`、只靠引用释放，TE patcher 还被谁引用着就不放。**未验**；单变量验法 = `graph:"h3_refall_cpuTE.json"`（TE 在 CPU、零显存占用）看 unet 是否 `loaded completely`。
- 结论：**≈40-45 s/步 × 20 = 800-900 s + 编码 ≈14-16 分钟/条**是「全 offload」这条路的稳态地板（677 实测 16 分 32 秒）。PDD 无关（零 LoRA 这条单根本没用 LoRA）；PDD 81 s/步是 308 条 patch 每次重贴的结构税，同源不同账。
